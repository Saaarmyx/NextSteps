# Historial de cambios

Todas los cambios notables de este proyecto se documentarán en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/),
y este proyecto sigue [Versionamiento Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-14

### Agregado

- Banner con imagen `Saaarmyx-Github.svg` y enlace a la página principal.
- Sección "Descripción" con descripción detallada de la aplicación.
- Sección "Características principales" con lista de funcionalidades: catálogo de planes, sesión firmada y endpoint de Telegram.
- Enlaces de tabla de contenidos para las nuevas secciones.

## [0.1.0] - 2026-07-01

### Agregado

- Primer commit con la estructura base del proyecto: aplicación React SPA con funciones serverless en Vercel, componentes en `src/components/`, datos de planes en `src/data/plans.ts`, hooks personalizados, endpoint `/api/telegram` y `/api/session`, pruebas con Vitest y Testing Library, `README.md`, `CHANGELOG.md` y `LICENSE`.
