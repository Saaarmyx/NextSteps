# Historial de cambios

Todas las cambios notables de este proyecto se documentarán en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/),
y este proyecto sigue [Versionamiento Semántico](https://semver.org/lang/es/).

## [Sin publicar]

### Agregado

- Catálogo de planes con selección accesible y modal de confirmación.
- Carta final con pétalos y fondo de jardín animado.
- Endpoints serverless con sesión firmada y validación de seguridad.
- Pruebas con Vitest, Testing Library y jsdom.

### Corregido

- El envío sin cookie válida responde `401`.
- La nota se sanea y se validan longitudes, fechas y horas antes de enviar.

### Mejorado

- La implementación se reemplazó por React 19, TypeScript 6 y Vite 8.
- El proyecto pasó a usar funciones serverless en Vercel.
